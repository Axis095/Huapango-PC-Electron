# Fuentes locales de Huapango

Familias originales de la interfaz, descargadas el 16 de octubre de 2026 desde
el repositorio oficial google/fonts, sin modificar los binarios. Distribuidas
bajo SIL Open Font License 1.1; cada licencia completa acompaña a su fuente.
No se requiere descargar fuentes cuando se ejecuta la aplicación.
